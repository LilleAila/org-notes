*** Obstructions to bipartiteness

Based on the above code, we can make the observation that the layers of BFS must have different colors. That is to say, a connected graph is bipartite iff there are no edges in the same BFS layer.

*Theorem*: A graph is bipartite if and only if it has no odd cycles.

+ Assume $G$ is bipartite and has an odd cycle $C$
  - $2$-coloring of $G$ is also a valid $2$-coloring of $C$.
  - $C$ cannot be $2$-colored!
+ Assume $G$ has no odd cycles and consider the BFS layers
  - If no edges are in the same layer, $G$ is bipartite
  - Otherwise we will find an odd cycle. This is a contradiction.
