** Overfitting

If we can create an arbitrarily deep tree by partitioning the tree, it is possible to perfectly classify any training dataset as long as there are no duplicates with different class labels. In these case, we will not be able to generalize. If we just create them arbitrarily, they will grow very large, and not be able to generalize well.

Ockham's razor says that we should prefer more compact decition trees that are not too specialized to the dataset.

Finding an optimal decision tree (the one that minimizes the expected number of tests) has been shown to be NP-hard. Thus, we typically learn the trees using greedy heuristics:

+ Start with an empty tree
+ Greedily, select a feature to split
+ Recurse

The idea is that whenever you choose a feature, you want to look at the distribution of the prediction label that is generated by dividing the dataset using that feature. Assuming we chose wind as the splitting feature, we will look at the distribution of the /Decision/-value of our output. The example above yields 2 no and 6 yes for weak, and 3 no and 3 yes for strong. We prefer this result to be homogenous (or as close as possible). If we achieve perfect purity, the result is homogenous and we have essentially solved the classification problem. In other words, we want to

+ Reduce uncertainty
+ Choose the feature which gives the highest information gain

** Measusing information

We want to find out in which case we are /most certain/ about the outcome, or which case the sample is more informative (on average). One way to measure this is using *entropy*. The entropy of a random variable $x$ measures the average information content that is obtained from a stochastic information source:

\[
H\left(x\right) = -\sum_i P\left(x = x_i\right) \log_2 P\left(x = x_i\right)
\]

In case of a binary variable, the value of $H\left(x\right)$ as a function of $P\left(X = 1\right)$ is

Here, we are plotting hwo the entropy $H\left(x\right)$ changes as we change the probability $P\left(x = 1\right)$. We see that entropy is minimal when the outcome is certain (either $0$ or $1$). The entropy increases as we approach a normal distribution. In other words, the entropy is $0$ when the information doesn't "surprise" us, so it gives no more information about the system. Conversely, the entropy is maximal when the probability of $x = 1$ is $\frac{1}{2}$. Here, we have no information about the otucomes adn cannot do any prediction on what the outcome will. The entropy is maximal, if the uncertainty is maximal.

*** Example

Given the same weather conditions dataset as used previously:

\begin{aligned}
H\left(\text{Decision}\right) & = -\sum_i P\left(\text{Decision} = i\right) \log P\left(\text{Decision} = i\right) \\
 & = -\left(P\left(\text{Decision} = \text{no}\right) \log P\left(\text{Decision} = \text{no}\right) + P\left(\text{Decision} = \text{yes}\right) \log P\left(\text{Decision} = \text{yes}\right)\right) \\
 & = - \left(\frac{5}{14} \log \frac{5}{14} + \frac{9}{14} \log \frac{9}{14}\right) \\
 &\approx 0.94
\end{aligned}

Note that entropy is not the only impurity measure. Some of them include:

+ Gini index $G\left(x\right) = \sum_i P\left(x = x_i\right)\left(1 - P\left(x = x_i\right)\right)$
+ Misclassification rate: $E = 1 - \max_i P\left(x = x_i\right)$

*** Conditional entropy

This is the amount of information about the outcome of a random variable $y$ when the value of a random variable $x$ is known. In other words, the amount of uncertainty fo $y$ when the value of $x$ is known.

\begin{aligned}
H\left(y | x\right) & = \sum_i P\left(x = x_i\right) H\left(y | x = x_i\right) \\
 & = -\sum_i P\left(x = x_i\right) \cdot \sum_j P\left(y = y_j | x = x_i\right) \log_2 P\left(y = y_j | x = x_i\right)
\end{aligned}

It describes how the value of a random variable $y$ changes as we observe $x$. We want to compute the entropy of our decision variable given wind:

\begin{aligned}
H\left(\text{Decision} |\text{Wind}\right) & = \sum_i P\left(\text{Wind} = i\right)H\left(\text{Decision} |\text{Wind} = i\right) \\
 & = \frac{8}{14} H\left(\text{Decision} |\text{Wind} = \text{wk}\right) + \frac{6}{14} H\left(\text{Decision} |\text{Wind} = \text{str}\right) \\
 H\left(\text{Decision} |\text{Wind} = \text{wk}\right) &\approx 0.81 \\
 H\left(\text{Decision} |\text{Wind} = \text{str}\right) & = 1 \\
 H\left(\text{Decision} |\text{Wind}\right) &\approx \frac{8}{14} \cdot 0.81 + \frac{6}{14} \cdot 1 = 0.892
\end{aligned}

We now want to measure how information changes when we split the data set based on the value of $x$.

*** Information gain

Information gain is an increase in information after splitting. Equivalently, it is a decrease in entropy (uncertainty) after splitting. We want to split on variables with high information gain.

\[
\text{IG}\left(x\right) = H\left(y\right) - H\left(y | x |\right)
\]

-----

Information gain of splitting on wind:

\begin{aligned}
\text{IG}\left(\text{Wind}\right) & = H\left(\text{Decision}\right) - H\left(\text{Decision} |\text{Wind}\right) \\
 &\approx 0.94 - 0.892 = 0.048
\end{aligned}

** Learning algorithm

The most common algorithm for learning a decision tree is *ID3* (Iterative Dichotomizer 3)

1. If all data points have the same label:
   - Return a leaf with that label
2. Else, if all data points have identical feature values:
   - Return a leaf with the most common label
3. Else:
   - Choose a feature that maximizes the information gain
   - Add a branch for each value of the feature
   - For each branch:
     * Call the algorithm recursively for the data points with the particular feature value

*** Notes

*Categorical variables*: If a feature has more than 2 values, it is still common to split only to two branches. Splits to several branches can be achieved by a sequence of binary splits. In this case, we will split on $x = y$ and $x \neq y$ rather than creating a branch for each value of $x$.

*Continuous variables*: There are an infinite number of possible split points. The algorithm is as mentioned based on heuristics. We choose a statistical function to decide on a split point. For example, it is common to use the mean or the median of the variable. This acts as a sort of hyperparameter on the algorithm.

** Overfitting and pruning

Typically, ID3 overfits to the training data. If there are no training points with identical feature values, ID3 will result in $100 %$ training accuracy. We will need an inductive bias preferring smaller trees. Otherwise, there will just be a leaf node for each point in the data set.

Ways to enforece this includes:

*Hard constraint*: set a minimum size for a leaf or maximum depth for the tree. This is however usually not enough on its own.
*Early stopping* (pre-pruning): stop recursion once information gain is non-positive. While ID3 selects the highest information, it may choose negative values if they are all negative. This is however problematic i some cases, and may not handle operations such as XOR.
*Pruning* (post-pruning): Build a full tree, then remove parts of it afterwards.

*** Reduced-Error pruning

1. Divide data into /training/ and /validation/ (pruning) data
2. Run ID3 with no modifications on the training data to build a full decision tree
3. For each subtree $T$:
   - If replacing the subtree with the majority label in $T$ does not decrease accuracy on the /validation data/:
     - Replace $T$ with a leaf node that predicts the majority class

** Properties of decision trees

Pros:
+ Fast (both to learn and predict)
+ Easy to interpret results and explain why a certain result was returned by looking at the tree
+ Invariant to scaling, since we only consider a single feature at every step
+ Can handle both categorical and continuous data
+ Implicit feature selection

Cons:
+ Unstable. Due to greedy learning, small differences in training data can result in completely different trees.

** Extension: Regression trees

Prediction values $y$ are determined using the points associated with the leaf, typically by averaging. There are some small modifications to the learning algorithm:
+ Instead of the impurity measurements, use squared error
+ Predict using mean value for the data subset
+ Information gain from a split is the squared error before the split - squared error after the split
