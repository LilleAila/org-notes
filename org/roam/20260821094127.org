* Introduction

K-Nearest Neighbours is a *classification algorithm* used for [[id:F701D30E-17F5-4AF6-A9D6-21CF8902B853][Supervised learning]].

Example:

[[file:./assets/20260821094610_screenshot.png]]

Data points have 2 features (coordinates) and two possible labels (either red rectangle or blue cross). Predict the labels of $A \left(0 , 0\right)$ and $B \left(2 , - 2\right)$.

+ *Inductive bias*: Similar objects have similar labels
+ *Algorithm*: Possibly the simplest possible classifier:
  * Find $k$ points that are most similar to the test point
  * Let them vote for the class label
+ *Hyper-parameter*: $k$ is chosen by the modeller

The important questions with this algorithm are:
1. How do we choose $k$?
2. When are objects similar?
3. How do we measure similarity?

Note that we usually want to choose odd numbers of $k$ when there are two different classes (like in this example), such that there are no ties. The decisian boundaries with $k = 1$ will just be determined by the nearest point:

As we can see, a value of $k$ that is too small will lead to overfitting, while a $k$ too large will be biased towards the dominant value. The solution would be to use the *validation vata* to determine the best value of $k$. While the training accuracy will actually decrease as we increase $k$, the validation accuracy will /increase/.

** Similarity

In this example, we have used euclidean distance as a measure of similarify. However, different types of data need different values for similarity. Other types of data include genetic strings, words, images, and probability distributions.

Common distance measures include
+ Euclidean distance: $d\left(x , z\right) = \sqrt{\sum_i \left(x_i - z_i\right)^2}$
+ Manhattan distance: $d\left(x , z\right) = \sum_i | x_i - z_i |$
+ $L_p - \text{norm}$: $\| x - z\|_p = \left(\sum_i | x_i - z_i |^p\right)^{\frac{1}{p}}$

It may be better to use domain-specific distance measures, and different distance measures will yield different results.

** Pros and cons of K-nearest neighbors

+ Pros
    - We make no assumptions about the data
    - Simple
    - Often yields a good accuraccy
    - Versatile (can be used both in classification and regression)
    - Can approximate any decision boundary with enough training points
+ Cons
    - High memory requirement
    - Prediction stage can be slow
    - Sensitive to irrelevant features and the scale of data
    - Hard to expand into more dimensions

* Extensions

+ Scalability
  - Classifying a point can require computing $n$ distances between $d$-dimensional objects
  - This can be limiting for large values of $n$ or $d$
  - Thus, we sometimes use specialized data structures such as kd-trees

+ Variants
  - Majority vote
  - Distance-weighted vote, for example inverse of distance or inverse of squared distance

+ Nearest neighbor regression is a method where instead of voting for the class of the test point, the continuous predictions from the neighbors are combined using combination methods such as averaging or local linear regression.
